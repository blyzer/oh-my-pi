# omp-kb

`omp-kb` builds a revision-aware code index from external SCIP producers or tree-sitter syntax. It stores the derived cache in the target Git worktree's Git directory, not in the source tree. The omp journal remains the session authority.

See the [knowledge-base guide](../../docs/knowledge-base/README.md#query-the-code-index) for commands, freshness rules, and limits.
