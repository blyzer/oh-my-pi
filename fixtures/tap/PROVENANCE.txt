DIVERGENCES THE PARSER MUST HANDLE
  version line
    node: TAP version 13; deno: TAP version 14; Perl: none (TAP 12 style)
  plan position
    node and deno: trailing plan; Perl with tests => N: leading plan; perl-truncated: no plan at all
  subtests
    node: 4-space indented child documents with their own trailing plan, each after a "# Subtest: <name>" comment; node prints "# Subtest:" before leaf tests too
    deno: steps as 4-space indented child documents
    both emit the correlated parent test point as not ok, with its own summary ("1 subtest failed", "1 test step failed.")
  failure location
    node: YAML key location: '<absolute path>:<line>:<column>', the test's declaration
    deno: the YAML block is a JSON flow mapping; at.file is relative to the working directory (./outcomes_test.ts) and at.line has no column
    Perl: no YAML; failure details go to stderr, which the parser does not read, so Perl failures carry file: None
  failure message
    node: YAML key error (plain, quoted or block scalar); deno: YAML key message
  directives
    node and deno: "# SKIP" (deno gives no reason) and "# TODO <reason>"; Perl: lowercase "# skip <reason>" on a test point with no description
  TODO diagnostics
    Perl prints failed-TODO diagnostics to stdout as # comments; ordinary failure diagnostics go to stderr
  hook failure (node)
    the child that never ran is not ok with failureType cancelledByParent; the cause sits on the parent (failureType hookFailed)
