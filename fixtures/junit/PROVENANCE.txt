JUnit XML fixtures. Each *.xml is a verbatim copy of a file a runner wrote. Never hand-edited.
Sources for each fixture live under sources/ and reproduce it with the command listed.

Shared outcomes in every runner: pass, fail (assertion), error (exception or setup failure), skip (ignored or disabled).

pytest.xml
  command: uv run --no-project --with pytest python -m pytest --junitxml=pytest.xml test_outcomes.py   (cwd sources/pytest)
  versions: python 3.12.14 (uv-managed), pytest 9.2.0, junit_family default (xunit2)
  error = autouse fixture raising at setup

pytest-xunit1.xml
  command: uv run --no-project --with pytest python -m pytest -o junit_family=xunit1 --junitxml=pytest-xunit1.xml test_outcomes.py
  versions: as pytest.xml

nextest.xml
  command: cargo nextest run --profile ci   (cwd sources/nextest)
  versions: cargo-nextest 0.9.148, cargo 1.99.0
  config: sources/nextest/.config/nextest.toml. Its [profile.ci] copies the repo's .config/nextest.toml CI settings (fail-fast false, retries 0). The only addition is [profile.ci.junit] path = "junit.xml". The repo's own .config/nextest.toml has no JUnit output.
  error = panicking test (exit 101), so it is a failure. No <error> element is produced.

nextest-abort.xml
  command: cargo nextest run --profile ci   (cwd sources/nextest-abort, same profile config)
  test calls std::process::abort(); emitted as <failure type="test abort">

jest.xml
  command: npx jest --ci   (cwd sources/jest, with jest.config.js reporter jest-junit, outputDirectory ".")
  versions: node v26.11.1, jest 30.5.2, jest-junit 17.0.0
  error = throw inside beforeAll (describe "setup"); emitted as a failure on test "setup errors"

surefire.xml
  command: mvn -B test   (cwd sources/junit5)
  versions: Apache Maven 3.9.12, OpenJDK 21.0.10 (Microsoft), junit-jupiter 5.11.4, maven-surefire-plugin 3.5.2
  error = non-assertion exception thrown from the test body (IllegalStateException)
  NOTE: <properties> embeds system properties, including user.name, user.home and java.io.tmpdir of the recording machine.
